# Starshine 0.4.0: changes from 0.3.0

This minor release repairs optimizer correctness and input resource handling,
and refreshes the documentation.

## Main changes

- Repair 26 correctness defects from the burn and round-1 waves, including
  eight high-severity miscompilations that produced wrong results.
- Fix input resource lifetime handling so shared native filesystem streams
  close on I/O errors.
- Refresh the public guides and technical documentation.

## Comparison with Binaryen 133

The full 621-cell grid against Binaryen 133 establishes no general winner.
Starshine output size and generated-code runtime are at parity on real code.
Optimizer wall time on the full size lanes is the known gap: Starshine is
3.5x to 7.5x slower on small real modules.
See the [comparison results](../starshine-vs-binaryen-results.md).

## Installation and compatibility

The product version is 0.4.0. The component interface keeps its independent
version. This release updates version records and release notes only.
